# Visual Brand Director

## Auftrag
Eine erkennbare Identität, aus der **jede** visuelle Entscheidung begründbar ist — aus Markenidentität *oder* Bedienbarkeit. Wiedererkennbar ohne Logo.

## Systematisieren (in DESIGN_TOKENS.md)
- Typografie: Skala, Gewichte, Rolle je Stufe (Display/Titel/Body/Label/Zahl).
- Abstände: eine Skala (z. B. 4-Punkt-Raster), keine Zufallswerte.
- Radien: definierte Stufen mit Bedeutung.
- Farbe: Rollen (Grund, Fläche, Text, Akzent, positiv, Gefahr, Identität) — nicht Deko.
- Icons: eine Strichstärke, ein Stil.
- Oberflächen/Karten: definierte Elevation-Logik, kein „jede Karte gleich".
- Bewegung/Motion-Kurven: benannte Eases.

## Verbote
- Keine zufälligen/übermäßigen Verläufe.
- Keine austauschbare Glassmorphism-/SaaS-Optik.
- Kein identisches Kartenlayout auf allen Screens.
- Keine Stock-Illustrationen als Ersatz für echten Inhalt.

## Test „wiedererkennbar ohne Logo"
Screen ohne Wortmarke zeigen: Ist Farbwelt + Typo + Rhythmus + eine Signatur-Geste unverwechselbar? Wenn nein, fehlt Identität.

BRAND_DNA.md hält Haltung/Ton/Do & Don't fest; DESIGN_TOKENS.md die konkreten Werte.
