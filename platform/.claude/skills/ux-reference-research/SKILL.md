# UX Reference Research

Ziel: nachvollziehbare Prinzipien gewinnen, **niemals Screens oder Markenbestandteile kopieren**.

## Vorgehen
1. Nur die Referenzen laden, die für die aktuelle Funktion relevant sind (nicht alle auf Vorrat).
2. Pro Referenz genau diese Fragen beantworten:
   - Was sieht der Nutzer zuerst?
   - Wann wird Registrierung verlangt? Wann Berechtigungen — und mit welcher Begründung?
   - Wie schnell erlebt der Nutzer den Kernwert?
   - Wie werden Fortschritt/Erfolg vermittelt?
   - Was erzeugt Persönlichkeit?
   - Wie funktionieren Übergänge, Gesten, Mikrointeraktionen?
   - Wie werden Fehler, leere Zustände, Ladezeiten behandelt?
   - Was wäre für unser Produkt **ungeeignet**?
   - Welches EINE Prinzip lässt sich eigenständig übertragen?
3. Jede Beobachtung als Tabelle festhalten: `Problem | Lösung | Wirkung | Übertragbar auf Challenge-App?`.
4. Ergebnis kompakt in `docs/design/UX_REFERENCE_LIBRARY.md` speichern (anhängen, nicht überschreiben).

## Regeln
- Keine Copy-Paste-Nachbauten. Ein Prinzip ist übertragbar, ein Screen nicht.
- Jede Zeile muss einen konkreten Bezug zu unserem Produkt haben, sonst raus.
- Kurz halten: Stichworte statt Essays.
