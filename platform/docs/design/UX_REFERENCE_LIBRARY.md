# UX Reference Library

Übertragbare Prinzipien aus hochwertigen Apps. **Keine Screen-Kopien** — nur Prinzipien,
die für unsere Challenge-App (echte Einsätze, echtes Preisgeld, In-App-Video) taugen.

| Referenz | Was zuerst? / Registrierung? | Prinzip (Problem → Lösung → Wirkung) | Für uns übertragbar |
| --- | --- | --- | --- |
| **TikTok** | Sofort echter Feed, kein Intro. Konto erst bei Interaktion. | Erklären ist langsam → sofort Kernwert zeigen → Sog ab Sekunde 1. | **Ja:** kalter Einstieg in echte Challenges statt Erklärfolien. |
| **Duolingo** | Ziel/Interesse wählen *vor* Konto; Fortschritt sichtbar. | Formular schreckt ab → erst spielen/wählen lassen → Commitment vor Hürde. | **Ja:** Interessen-Wahl baut sichtbar den Feed, Konto später. |
| **Revolut** | Starke Zahl-Hierarchie, sofortiges Feedback. | Komplexität überfordert → eine große Zahl + klare Aktion → Wertgefühl. | **Ja:** Preisgeld als große, animierte Held-Zahl. |
| **Airbnb** | Echte Angebote, Vertrauen durch Menschen/Belege. | Unsicherheit → echte Inhalte + soziale Belege → Vertrauen, klare Wahl. | **Ja:** echte Teilnehmer-Avatare, „X sind dabei", Restplätze. |
| **BeReal** | Dringlichkeit + Kamera zentral, niedrige Einstiegshürde. | Zögern → Zeitfenster/Knappheit → sofortige Beteiligung. | **Ja:** Countdown/Restplätze erzeugen echten Einsatz; Kamera erst bei Teilnahme. |
| **Headspace** | Ruhige Atmosphäre, freundlicher, menschlicher Ton. | Kälte/Technik-Sprech → warme Microcopy + Identität → emotionale Bindung. | **Teilweise:** Ton menschlich, aber mutiger/rebellischer, nicht sanft-meditativ. |
| **Linear** | Präzision, Tempo, konsistente Mikrointeraktionen. | Trägheit wirkt billig → schnelle, präzise Reaktionen → Premium-Gefühl. | **Ja:** < 100 ms Feedback, konsistente Eases, kein Ruckeln. |

## Bewusst NICHT übernommen
- Headspace-Sanftheit/Pastell → widerspricht „mutig, leicht rebellisch".
- Klassische Airbnb-Foto-Grids → wir haben (noch) keine echten Cover-Bilder; Stock ist verboten.
- Onboarding-Tutorials mit Overlay-Pfeilen (viele Apps) → erklärt, was Benutzung ohnehin zeigt.

## Ein-Satz-Essenz für unser Onboarding
Wie TikTok sofort in echten Wert, wie Duolingo Interessen vor Konto, wie Revolut das
Preisgeld als große lebendige Zahl, wie Airbnb/BeReal echte Menschen + Knappheit als
Vertrauen und Einsatz — Registrierung erst bei Teilnahme.
